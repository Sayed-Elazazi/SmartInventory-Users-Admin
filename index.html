الاتصال الآمن بـ GitHub

استخدم اسم حساب GitHub ورمز وصول شخصياً بصلاحية Contents للاتصال بملف المستخدمين.

مهم: الصفحة مستضافة في SmartInventory-Users-Admin، لكن ملف المستخدمين موجود في المستودع الخاص SmartInventory-Users. أنشئ الرمز للمستودع SmartInventory-Users تحديداً (وليس SmartInventory-Users-Admin)، بصلاحية Contents: Read and write. لا يُحفظ الرمز في المتصفح أو GitHub Pages. إنشاء رمز GitHub
