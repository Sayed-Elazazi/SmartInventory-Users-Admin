# لوحة إدارة مستخدمي SmartInventory

صفحة الإدارة المنشورة:

`https://sayed-elazazi.github.io/SmartInventory-Users-Admin/`

هذا المستودع العام يحتوي واجهة HTML وملفات النشر فقط. بيانات المستخدمين
تبقى في المستودع الخاص `Sayed-Elazazi/SmartInventory-Users` ولا تُنسخ إلى
موقع Pages.

## الدخول

أنشئ Fine-grained personal access token لحساب GitHub المخوّل، وحدد المستودع
الخاص `SmartInventory-Users` فقط، وامنحه صلاحية **Contents: Read and write**.
افتح صفحة الإدارة وأدخل اسم حساب GitHub والرمز. يبقى الرمز في ذاكرة الصفحة
خلال الجلسة ولا يُحفظ في ملفات الموقع أو التخزين المحلي للمتصفح.

لا تجعل مستودع البيانات عاماً ولا تضع الرمز في هذا المستودع. يمكن لأي شخص
فتح واجهة Pages، لكن الوصول إلى البيانات والتعديل عليها يتطلب رمزاً مخوّلاً
للمستودع الخاص.

## النشر

يُنشر `index.html` بواسطة GitHub Actions. لا يحتوي ناتج النشر على `users.csv`
أو ملفات Python. يمكن متابعة التشغيل من تبويب **Actions** في هذا المستودع.
